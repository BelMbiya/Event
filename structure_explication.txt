=======================================================
EXPLICATION DE LA STRUCTURE DU PROJET LARAVEL - EVENT
=======================================================

## 📁 DOSSIER VIEWS (resources/views)
=====================================

### Rôle général :
Le dossier views contient tous les templates Blade (interface utilisateur) de l'application.

### Structure et rôles :

📂 **admin/**
- admin/index.blade.php : Page d'accueil de l'interface d'administration
- admin.blade.php : Template principal avec sidebar et navigation (layout de base)

📂 **auth/**
- auth/login.blade.php : Page de connexion utilisateur

📂 **event/**
- event/selection.blade.php : Page de sélection d'événement *

📂 **events/**
- events/drinks-modals.blade.php : Modales pour la gestion des boissons
- events/drinks-pdf.blade.php : Template PDF pour l'export des boissons
- events/drinks.blade.php : Interface de gestion des boissons

📂 **guest_book/**
- guest_book/index.blade.php : Page principale du livre d'or
- guest_book/pdf.blade.php : Template PDF pour l'export du livre d'or

📂 **guests/**
- guests/all-guests-pdf.blade.php : Export PDF de tous les invités
- guests/create.blade.php : Formulaire de création d'invité
- guests/drink-choices-pdf.blade.php : Export PDF des choix de boissons
- guests/drink-choices.blade.php : Interface des choix de boissons
- guests/eventdrink.blade.php : Gestion des boissons par événement
- guests/single-guest-pdf.blade.php : Export PDF d'un invité individuel

📂 **invitation/**
- invitation/content.blade.php : Gestion du contenu des invitations *
- invitation/create-advanced.blade.php : Création avancée d'invitation
- invitation/edit-advanced.blade.php : Édition avancée d'invitation
- invitation/edit-content.blade.php : Édition du contenu d'invitation *
- invitation/index.blade.php : Liste des invitations
- invitation/preview.blade.php : Aperçu des invitations
- invitation/invitation_paper/ : Dossier contenant les modèles et images d'invitations
- invitation/pdf/all-invitations.blade.php : Export PDF de toutes les invitations

📄 **Fichiers racine :**
- welcome.blade.php : Page d'accueil simple
- dashboard-enhanced.blade.php : Tableau de bord amélioré
- default.blade.php : Template par défaut

## 🗃️ MIGRATIONS (database/migrations)
=====================================

### Rôle général :
Les migrations définissent la structure de la base de données (création/modification des tables).

### Migrations système Laravel :
- 0001_01_01_000000_create_users_table.php : Table des utilisateurs
- 0001_01_01_000001_create_cache_table.php : Table de cache
- 0001_01_01_000002_create_jobs_table.php : Table des tâches en file d'attente

### Migrations métier :

📊 **Tables principales :**
- 2025_08_23_162153_create_event_types_table.php : Types d'événements (mariage, anniversaire...)
- 2025_08_23_162311_create_events_table.php : Table principale des événements
- 2025_08_23_162757_create_event_tables_table.php : Tables physiques de l'événement
- 2025_08_23_163150_create_guests_table.php : Liste des invités
- 2025_08_23_163857_create_guest_books_table.php : Livre d'or des invités
- 2025_08_25_135052_create_invitations_table.php : Invitations envoyées

📊 **Tables de classification :**
- 2025_08_23_163031_create_guest_types_table.php : Types d'invités (VIP, famille...)
- 2025_08_23_163032_create_guest_categories_table.php : Catégories d'invités

📊 **Tables des boissons :**
- 2025_08_23_164944_create_drinks_table.php : Catalogue des boissons
- 2025_08_23_165341_create_event_drinks_table.php : Boissons disponibles par événement
- 2025_08_23_165532_create_guest_drink_choices_table.php : Choix de boissons des invités

📊 **Tables annexes :**
- 2025_08_23_164433_create_galleries_table.php : Galerie photos de l'événement
- 2025_08_23_164646_create_payments_table.php : Paiements

## 🌱 SEEDERS (database/seeders)
==============================

### Rôle général :
Les seeders peuplent la base de données avec des données de test ou initiales.

### Seeders principaux :
- DatabaseSeeder.php : Seeder principal qui appelle tous les autres
- DatabaseSeederMinimal.php : Version minimale pour tests rapides
- MinimalDataSeeder.php : Données essentielles uniquement

### Seeders par entité :

👥 **Utilisateurs et événements :**
- UserSeeder.php : Création d'utilisateurs de test
- EventTypeSeeder.php : Types d'événements prédéfinis
- EventSeeder.php : Événements de démonstration
- EventDrinkSeeder.php : Association boissons/événements

👥 **Invités :**
- GuestTypeSeeder.php : Types d'invités
- GuestCategorySeeder.php : Catégories d'invités
- GuestSeeder.php : Invités de test
- GuestDrinkChoiceSeeder.php : Choix de boissons des invités
- GuestBookSeeder.php : Messages du livre d'or

📧 **Invitations :**
- InvitationSeeder.php : Invitations de test
- InvitationContentSeeder.php : Contenu des invitations
- TestInvitationSeeder.php : Invitations pour tests

🍷 **Boissons :**
- DrinkSeeder.php : Catalogue des boissons
- CongoleseDrinksSeeder.php : Boissons congolaises spécialisées
- DrinkPricesSeeder.php : Prix des boissons

📝 **Contenu :**
- ContentSeeder.php : Contenu personnalisable
- AdvancedContentSeeder.php : Contenu avancé
- FixNullFieldsSeeder.php : Correction des champs vides

## 🎮 CONTRÔLEURS (app/Http/Controllers)
=====================================

### Rôle général :
Les contrôleurs gèrent la logique métier et la communication entre les vues et les modèles.

### Contrôleur de base :
- Controller.php : Classe abstraite de base pour tous les contrôleurs

### Contrôleurs par domaine :

🏠 **Administration :**
- Admin/IndexController.php : Gestion de l'interface d'administration
- Admin/EnhancedDashboardController.php : Tableau de bord amélioré

🔐 **Authentification :**
- Auth/AuthController.php : Gestion de la connexion/déconnexion

📅 **Événements :**
- Event/EventSelectionController.php : Sélection et gestion des événements
- EventDrinkController.php : Gestion des boissons par événement

👥 **Invités :**
- Guest/GuestController.php : CRUD des invités
- Guest/GuestBookController.php : Gestion du livre d'or
- Guest/DrinkChoicesController.php : Gestion des choix de boissons
- Guest/GuestDrinkChoiceController.php : Choix individuels des invités

📧 **Invitations :**
- Invitation/InvitationController.php : CRUD des invitations
- Invitation/ContentController.php : Gestion du contenu des invitations

🍷 **Boissons :**
- DrinkController.php : Gestion du catalogue des boissons

=======================================================
RÉSUMÉ GÉNÉRAL
=======================================================

Ce projet Laravel est une application de gestion d'événements qui permet :
- Création et gestion d'événements
- Invitation et suivi des invités
- Gestion des choix de boissons
- Livre d'or interactif
- Génération de PDF et invitations
- Interface d'administration complète

L'architecture suit le pattern MVC de Laravel avec une séparation claire entre :
- Les vues (Blade templates) pour l'interface utilisateur
- Les contrôleurs pour la logique métier
- Les migrations pour la structure de données
- Les seeders pour les données de test
